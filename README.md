# APIStrike ⚔️

A modular, AI-assisted, open-source **automated API penetration testing** framework
covering the OWASP API Security Top 10.

> ⚠️ **Authorized use only.** Run APIStrike only against systems you own or are
> explicitly authorized to test. A required `scope.yaml` allowlist gates every request.

## Status
🚧 Early development — see the phased roadmap.

## Stack
Python 3.11+ · Typer · httpx · SQLite · Jinja2 · Ollama (local AI) · Docker

## Quick start
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
